vibeads

Contextual dev-tool discovery for Claude Code.

npx vibeads

What it does

vibeads is contextual dev-tool discovery for Claude Code. It looks at what you’re building and surfaces relevant a16z portfolio tools that fit the task — inside the tool you already use.

  • Surfaces relevant a16z portfolio tools while you build
  • Suggestions follow the task at hand, not a generic list
  • Lives inside Claude Code as a skill
  • Installs with a single npx command
