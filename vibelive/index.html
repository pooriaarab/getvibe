vibelive

Multiplayer for agent terminals.

npx vibelive

What it does

vibelive makes agent terminals multiplayer. Open up a session and other people can be in the same terminal, watching the same agent work, as it happens.

  • One agent terminal, multiple people, real time
  • Everyone sees the same session as it unfolds
  • Made for pairing, reviews, and demos
  • The session stays on your machine — sharing is a layer on top
