vibenotifications

Customizable notifications for Claude Code.

npx vibenotifications

What it does

vibenotifications keeps you posted while Claude Code works. Set up the notifications you care about — GitHub PRs, Slack DMs, stock prices, and more — and step away without losing the thread.

  • GitHub PRs, Slack DMs, stock prices, and more
  • Customizable: you pick what interrupts you and what waits
  • Built to run alongside Claude Code
  • Installs with a single npx command
