vibeshare

Share your live agent session by URL.

npx vibeshare-live

What it does

vibeshare gives your live agent session a URL. Run one command and anyone with the link can watch the session unfold in their browser — no install on their side.

  • One command turns a running session into a link
  • Viewers watch live in a browser — nothing to install
  • The link stops working when you end the session
  • Streams from your machine, under your control
