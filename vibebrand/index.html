vibebrand

Generate a tokenized brand/design system — pick a direction, get design tokens.

npx vibebrand

What it does

vibebrand generates a complete, tokenized brand/design system. Pick one of 14 directions and get CSS design tokens (light + dark), fonts, and a brand-kit starting point — SDK + CLI, one command.

  • Pick from 14 brand/design directions
  • CSS design tokens for light and dark themes
  • Fonts and a brand-kit starting point
  • SDK + CLI — installs with a single npx command
