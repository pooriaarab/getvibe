What it does

vibedate is dating by token league. Your agent usage says something about you — vibedate matches people whose agents burn tokens in the same league as yours.

  • Matches by token league — your agent usage is the profile
  • Leagues keep every match in your weight class
  • Runs local-first: your stats stay yours
  • Join with a single npx command
